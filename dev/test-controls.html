Controls Test Page

Manual test page for <panel-live-config>, <panel-live-controls>, and PanelLive.runAll().

Test 1: Config + Controls

The config element reads localStorage and the controls toolbar provides Run All + auto-run toggle.

Test 2: Three panel-live elements (auto-run disabled by default)

These should NOT auto-run on page load (unless auto-run toggle is ON in localStorage). Click "Run All" above to execute them.

Example 1: Simple text

import panel as pn pn.panel("Hello from Example 1!").servable()

Example 2: Slider

import panel as pn slider = pn.widgets.FloatSlider(start=0, end=10, name='Value') pn.Row(slider, pn.bind(lambda v: f'Value: {v:.1f}', slider)).servable()

Example 3: Markdown

import panel as pn pn.panel("## Example 3\n\nThis is **Markdown** content.").servable()
