# Polars

Create, filter, and aggregate a Polars DataFrame with `group_by` operations.

**Why it fails:** Polars was available in Pyodide v0.27.0 but is no longer included. The Pyodide team states that Polars is disabled because they are waiting on the Polars maintainers to build a version for the updated ABI. See [Pyodide 0.28 release notes](https://blog.pyodide.org/posts/0.28-release/).

Docs: [Polars](https://docs.pola.rs/)
